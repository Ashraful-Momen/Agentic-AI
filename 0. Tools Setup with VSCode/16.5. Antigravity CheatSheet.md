## ২. প্রয়োজনীয় MCP টুলস (Model Context Protocol)

| MCP Server | অ্যাক্টিভেশন উদ্দেশ্য | ব্যবহারের প্রধান ক্ষেত্র |
| --- | --- | --- |
| **Filesystem MCP** | ডিরেক্টরি স্ক্যান ও ডিপ ফাইল রিড/রাইট | একাধিক ফাইল একসাথে রিফ্যাক্টর ও কনটেক্সট লোড করা |
| **Git / GitHub MCP** | গিট অপারেশন ও ব্রাঞ্চ ম্যানেজমেন্ট | কমিট হিস্ট্রি, স্ট্যাশ, পিআর ড্রাফটিং ও ব্রাঞ্চিং |
| **Docker MCP** | কনটেইনার ও সার্ভিস লাইফসাইকেল | লোকাল ডাটাবেস, কনটেইনার স্টেট ও লগ ট্র্যাকিং |
| **PostgreSQL / DB MCP** | লাইভ স্কিমা ও কোয়েরি ভেরিফিকেশন | মাইগ্রেশন চেক ও কোড পরিবর্তনের পর টেবিল স্কিমা ভ্যালিডেশন |
| **Puppeteer / Playwright MCP** | ব্রাউজার রানটাইম ও ডম অডিট | ব্রাউজার রেন্ডারিং, কনসোল এরর ও ভিজ্যুয়াল ইভেন্ট টেস্ট |

## ৩. প্রজেক্টের লাইফসাইকেল চেকলিস্ট

### ক. প্রজেক্ট শুরু করার আগে (Pre-flight Phase)

1. **স্টেট ভেরিফিকেশন:** `.agents/state/todo.md` এবং `memory.md` ফাইলে অবজেক্টিভ ও কনস্ট্রেইন্ট স্পষ্ট রাখা।
2. **পরিবেশ নিশ্চিতকরণ:** ডিপেন্ডেন্সি ইন্সটল এবং ডকার সার্ভিসসমূহ (`docker-compose up -d`) চালু করা।
3. **এজেন্ট ইনিশিয়ালাইজেশন:** চ্যাট উইন্ডোতে `@AGENTS.md` লোড করে এজেন্টকে ইনিশিয়াল কনটেক্সট দেওয়া।

### খ. ব্রাউজার-বেসড টেস্টিং (Testing Phase)

1. লোকালহোস্ট সার্ভার চালু থাকা অবস্থায় চ্যাটে বা CLI-তে `/browser` কল করা।
2. কনসোল লগ ও নেটওয়ার্ক রিকোয়েস্ট মনিটর করা (বিশেষ করে 4xx/5xx এরর)।
3. ডম এলিমেন্ট ইন্টারঅ্যাকশন (ফর্ম সাবমিট, নেভিগেশন, বাটন ক্লিক) ভেরিফাই করা।
4. ফেইলিউর স্টেটের জন্য স্ক্রিনশট বা টেস্ট লগ আর্টিফ্যাক্ট হিসেবে সেভ করা।

### খ. বাস্তব প্রজেক্টে ইনলাইন প্রম্পট ব্যবহারের উদাহরণ (Real-world Inline Prompt Examples)

বাস্তব প্রজেক্টে সরাসরি চ্যাট বা প্রম্পট ইনপুটে যেভাবে ইনলাইনে কমান্ড, আর্গুমেন্ট, ফাইল ট্যাগ (`@file`) এবং ইনস্ট্রাকশন একসাথে টাইপ করবেন:

1. **`/plan` (প্ল্যানিং ও আর্কিটেকচার ড্রাফট):**
   ```text
   /plan Implement JWT authentication with refresh token rotation using @src/auth/auth.service.ts and create unit test specs in @tests/auth.test.ts
   ```
   *ব্যবহারিক প্রয়োগ:* কোড পরিবর্তন না করে প্রথমে এক্সিকিউশন স্টেপস, সিকিউরিটি ঝুঁকি ও ডেটা ফ্লোর একটি প্ল্যান আর্টিফ্যাক্ট তৈরি করে।

2. **`/context` (কনটেক্সট পিনপয়েন্ট ও টোকেন সাশ্রয়):**
   ```text
   /context @src/modules/payment/ @src/types/order.ts focus only on Stripe webhook signature verification and ignore legacy PayPal handlers
   ```
   *ব্যবহারিক প্রয়োগ:* চ্যাটের কনটেক্সট উইন্ডো কেবল উল্লেখিত ফাইলে সীমাবদ্ধ রাখে, ফলে টোকেন বাঁচে এবং হ্যালুসিনেশন রোধ হয়।

3. **`/browser` (অটোমেটেড ব্রাউজার টেস্টিং ও ডম অডিট):**
   ```text
   /browser http://localhost:3000/checkout - Test coupon code 'DISCOUNT20', verify total price updates dynamically, and assert no 4xx/5xx errors in console
   ```
   *ব্যবহারিক প্রয়োগ:* ব্রাউজার সাব-এজেন্ট লাইভ ব্রাউজারে ইনপুট পূরণ, বাটন ক্লিক এবং নেটওয়ার্ক লগ চেক করে ভেরিফিকেশন রিপোর্ট দেয়।

4. **`/review` (গিট ডিফের প্রফেশনাল অডিট):**
   ```text
   /review staged changes: Scan for potential SQL injection vulnerabilities, memory leaks, and unhandled promise rejections before creating PR
   ```
   *ব্যবহারিক প্রয়োগ:* লোকাল গিট ডিফের পুঙ্খানুপুঙ্খ সিকিউরিটি, টাইপিং এবং ক্লিন-কোড অডিট করে সমস্যা চিহ্নিত করে।

5. **`/sync-state` (স্টেট ও স্প্রিন্ট আপডেট):**
   ```text
   /sync-state Record completed milestone 'OAuth2 Google & GitHub Login' in progress.md and check off Task #4 in todo.md
   ```
   *ব্যবহারিক প্রয়োগ:* সেশনের কাজের অগ্রগতি `.agents/state/progress.md` এবং `todo.md`-তে অটো-আপডেট করে।

6. **`/goal` (অটোনোমাস লং-রানিং টাস্ক):**
   ```text
   /goal Refactor all legacy callback functions in @src/dao/ to async/await syntax and ensure 'npm test' passes with 100% success rate
   ```
   *ব্যবহারিক প্রয়োগ:* পুরো টাস্ক শতভাগ সম্পন্ন না হওয়া পর্যন্ত এজেন্ট একটানা কাজ চালিয়ে যায় (বিল্ড, টেস্ট ও সেলফ-কারেকশন সহ)।

7. **`/schedule` (ব্যাকগ্রাউন্ড ক্রন ও টাইমার মনিটরিং):**
   ```text
   /schedule cron="*/15 * * * *" Monitor http://localhost:8080/health and alert me immediately if status is not 200 OK
   ```
   *ব্যবহারিক প্রয়োগ:* নির্ধারিত সময়সূচি অনুযায়ী ব্যাকগ্রাউন্ডে মনিটরিং স্ক্রিপ্ট চালায়।

8. **`/grill-me` (ইন্টারঅ্যাক্টিভ আর্কিটেকচার ইন্টারভিউ):**
   ```text
   /grill-me Grill me on edge cases, database constraints, and race conditions for the new multi-tenant billing system before planning
   ```
   *ব্যবহারিক প্রয়োগ:* কোড বা প্ল্যান শুরুর আগে এজেন্ট ইন্টারভিউয়ারের মতো প্রশ্ন করে আপনার প্রয়োজনীয়তা ও ডিজাইন নিখুঁত করে নেয়।

9. **`/learn` (নিয়ম বা প্রেফারেন্স স্থায়ী মেমোরিতে সেভ করা):**
   ```text
   /learn Always use zod for schema validation in API controllers and handle exceptions with the custom AppError class
   ```
   *ব্যবহারিক প্রয়োগ:* ইউজারের পছন্দ বা নির্দেশনা প্রজেক্টের রুলস ও মেমোরিতে লিখে রাখে যাতে পরবর্তী সব সেশনে এজেন্ট এটি মেনে চলে।

10. **`/deploy-dry` (ডিপ্লয়মেন্ট ড্রাই রান):**
    ```text
    /deploy-dry staging --config docker-compose.prod.yml --env-file .env.staging --check-ports
    ```
    *ব্যবহারিক প্রয়োগ:* সরাসরি ডেপ্লয় না করে এনভায়রনমেন্ট ভেরিয়েবল, পোর্ট ম্যাপিং ও ডকার বিল্ডের কনফিগ ড্রাই রান ভ্যালিডেশন করে।

### গ. ইনলাইন কোড এডিটর মোডালিটি (Inline Code Edit via `Ctrl+I` / `Cmd+I`)

সরাসরি কোড এডিটরে লাইন বা ফাংশন সিলেক্ট করে ইনলাইন প্রম্পট উইন্ডোতে নির্দেশ দেওয়ার বাস্তব উদাহরণ:

* **সিলেক্টেড ফাংশন রিফ্যাক্টরিং:**
  `Ctrl + I` চেপে প্রম্পট দিন:
  ```text
  Refactor this function to handle null safety, add early returns, and include typed JSDoc comments.
  ```
* **টাইপ ডেফিনিশন জেনারেশন:**
  অবজেক্ট বা ফাংশনের উপর কার্সর রেখে `Ctrl + I` চেপে প্রম্পট দিন:
  ```text
  Generate a strict TypeScript interface for this payload matching @src/types/base.ts.
  ```
* **ইউনিট টেস্ট স্ক্যাফোল্ডিং:**
  ফাংশন সিলেক্ট করে `Ctrl + I` চেপে প্রম্পট দিন:
  ```text
  Write Jest unit tests covering edge cases (empty array, negative numbers, timeout) for this function.
  ```

## ৫. বেস্ট পারফরম্যান্স কনফিগারেশন ও এফিশিয়েন্ট ওয়ার্কফ্লো

* **টার্মিনাল পলিসি:** `Settings > Advanced > Agent Security Mode`-এ গিয়ে `Trusted / Non-destructive Auto-Approval` সেট করুন, যাতে `npm`, `git`, `docker` রান করতে বারবার ম্যানুয়াল কনফার্মেশন দিতে না হয়।

### B. Real-world Inline Prompt Examples

Real-world examples showing how to type commands inline with parameters, file tags (`@file`), and instructions:

1. **`/plan` (Implementation Blueprint):**
   ```text
   /plan Implement JWT authentication with refresh token rotation using @src/auth/auth.service.ts and create unit test specs in @tests/auth.test.ts
   ```
   *Purpose:* Drafts execution phases, data flow, and threat models as an artifact without modifying code yet.

2. **`/context` (Precise Token Focusing):**
   ```text
   /context @src/modules/payment/ @src/types/order.ts focus only on Stripe webhook signature verification and ignore legacy PayPal handlers
   ```
   *Purpose:* Constrains model attention strictly to relevant code, reducing hallucination and preserving token budget.

3. **`/browser` (Automated E2E & DOM Diagnostics):**
   ```text
   /browser http://localhost:3000/checkout - Test coupon code 'DISCOUNT20', verify total price updates dynamically, and assert no 4xx/5xx errors in console
   ```
   *Purpose:* Subagent opens the browser, fills forms, simulates clicks, and captures screenshots or errors.

4. **`/review` (Pre-PR Quality & Security Audit):**
   ```text
   /review staged changes: Scan for potential SQL injection vulnerabilities, memory leaks, and unhandled promise rejections before creating PR
   ```
   *Purpose:* Inspects git diff against best practices and security baselines.

5. **`/sync-state` (Sprint & Progress Bookkeeping):**
   ```text
   /sync-state Record completed milestone 'OAuth2 Google & GitHub Login' in progress.md and check off Task #4 in todo.md
   ```
   *Purpose:* Keeps `.agents/state/` documentation synchronized with minimal manual effort.

6. **`/goal` (Autonomous Long-running Task):**
   ```text
   /goal Refactor all legacy callback functions in @src/dao/ to async/await syntax and ensure 'npm test' passes with 100% success rate
   ```
   *Purpose:* Agent works continuously until all criteria are met, self-correcting any build or test failures.

7. **`/schedule` (Recurring Background Monitoring):**
   ```text
   /schedule cron="*/15 * * * *" Monitor http://localhost:8080/health and alert me immediately if status is not 200 OK
   ```
   *Purpose:* Automates routine monitoring tasks without tying up the active conversation thread.

8. **`/grill-me` (Design Alignment Interview):**
   ```text
   /grill-me Grill me on edge cases, database constraints, and race conditions for the new multi-tenant billing system before planning
   ```
   *Purpose:* Agent asks rigorous architectural questions to solidify design before coding.

9. **`/learn` (Persistent Memory & Style Guidelines):**
   ```text
   /learn Always use zod for schema validation in API controllers and handle exceptions with the custom AppError class
   ```
   *Purpose:* Persists rules into `.agents/rules/` so future agent runs follow them automatically.

10. **`/deploy-dry` (Dry-run Deployment Parity):**
    ```text
    /deploy-dry staging --config docker-compose.prod.yml --env-file .env.staging --check-ports
    ```
    *Purpose:* Validates configuration, variables, and port bindings before actual cluster rollout.
