## ২. প্রয়োজনীয় MCP টুলস (Model Context Protocol)

| MCP Server                           | অ্যাক্টিভেশন উদ্দেশ্য                            | ব্যবহারের প্রধান ক্ষেত্র                                                             |
| ------------------------------------ | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Filesystem MCP**             | ডিরেক্টরি স্ক্যান ও ডিপ ফাইল রিড/রাইট | একাধিক ফাইল একসাথে রিফ্যাক্টর ও কনটেক্সট লোড করা                  |
| **Git / GitHub MCP**           | গিট অপারেশন ও ব্রাঞ্চ ম্যানেজমেন্ট     | কমিট হিস্ট্রি, স্ট্যাশ, পিআর ড্রাফটিং ও ব্রাঞ্চিং                 |
| **Docker MCP**                 | কনটেইনার ও সার্ভিস লাইফসাইকেল              | লোকাল ডাটাবেস, কনটেইনার স্টেট ও লগ ট্র্যাকিং                          |
| **PostgreSQL / DB MCP**        | লাইভ স্কিমা ও কোয়েরি ভেরিফিকেশন         | মাইগ্রেশন চেক ও কোড পরিবর্তনের পর টেবিল স্কিমা ভ্যালিডেশন |
| **Puppeteer / Playwright MCP** | ব্রাউজার রানটাইম ও ডম অডিট                     | ব্রাউজার রেন্ডারিং, কনসোল এরর ও ভিজ্যুয়াল ইভেন্ট টেস্ট     |

## ৩. প্রজেক্টের লাইফসাইকেল চেকলিস্ট

### ক. প্রজেক্ট শুরু করার আগে (Pre-flight Phase)

1. **স্টেট ভেরিফিকেশন:** `.agents/state/todo.md` এবং `memory.md` ফাইলে অবজেক্টিভ ও কনস্ট্রেইন্ট স্পষ্ট রাখা।
2. **পরিবেশ নিশ্চিতকরণ:** ডিপেন্ডেন্সি ইন্সটল এবং ডকার সার্ভিসসমূহ (`docker-compose up -d`) চালু করা।
3. **এজেন্ট ইনিশিয়ালাইজেশন:** চ্যাট উইন্ডোতে `@AGENTS.md` লোড করে এজেন্টকে ইনিশিয়াল কনটেক্সট দেওয়া।

### খ. ব্রাউজার-বেসড টেস্টিং (Testing Phase)

1. লোকালহোস্ট সার্ভার চালু থাকা অবস্থায় চ্যাটে বা CLI-তে `/browser` কল করা।
2. কনসোল লগ ও নেটওয়ার্ক রিকোয়েস্ট মনিটর করা (বিশেষ করে 4xx/5xx এরর)।
3. ডম এলিমেন্ট ইন্টারঅ্যাকশন (ফর্ম সাবমিট, নেভিগেশন, বাটন ক্লিক) ভেরিফাই করা।
4. ফেইলিউর স্টেটের জন্য স্ক্রিনশট বা টেস্ট লগ আর্টিফ্যাক্ট হিসেবে সেভ করা।

## ৫. বেস্ট পারফরম্যান্স কনফিগারেশন ও এফিশিয়েন্ট ওয়ার্কফ্লো

* **টার্মিনাল পলিসি:** `Settings > Advanced > Agent Security Mode`-এ গিয়ে `Trusted / Non-destructive Auto-Approval` সেট করুন, যাতে `npm`, `git`, `docker` রান করতে বারবার ম্যানুয়াল কনফার্মেশন দিতে না হয়।
* **কম প্রম্পটে বেশি আউটপুট:**
* চ্যাটে কোড কপি-পেস্ট না করে সরাসরি `@file:symbol` অথবা `@path` মেনশন করুন।
* চ্যাটে পুরো ফাইল নতুন করে প্রিন্ট না করিয়ে ইন-এডিটর **Diff View** দেখে কোড এক্সেপ্ট করুন।
* বারবার ব্যাকগ্রাউন্ড ব্রিফিং না দিয়ে এজেন্টকে নির্দেশ দিন যেন সে সরাসরি `.agents/state/` ডিরেক্টরি থেকে মেমোরি পড়ে নেয়।
